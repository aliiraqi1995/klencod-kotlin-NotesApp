# NotesApp

مشروع أندرويد بسيط (Kotlin + Jetpack Compose): إضافة وحذف وعرض ملاحظات.

## التشغيل
1. افتح المجلد في Android Studio (أحدث نسخة).
2. انتظر مزامنة Gradle.
3. شغّل على محاكي أو جهاز حقيقي (minSdk 24).

## البنية
- `app/build.gradle.kts` إعدادات المشروع والتبعيات
- `MainActivity.kt` الواجهة والمنطق (ملاحظات في الذاكرة)
